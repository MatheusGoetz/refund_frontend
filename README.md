# 💸 Refund Frontend

Interface web do sistema de gerenciamento de reembolsos.  
Aplicação **SPA moderna**, construída com **React 19 + TypeScript + Vite + Tailwind CSS**, focada em performance, experiência do usuário e código escalável.

Este frontend consome a API do projeto **refund_backend**, permitindo visualizar e gerenciar solicitações de reembolso de forma simples e intuitiva.

---

## 🧠 Sobre o projeto

O **Refund Frontend** foi desenvolvido para atuar como painel de controle de reembolsos, oferecendo uma experiência fluida e responsiva.

O projeto foi estruturado seguindo boas práticas de frontend moderno:
- Componentização limpa
- Tipagem forte
- Roteamento SPA
- Consumo de API REST
- Estilização utilitária de alta performance

Ideal para portfólio profissional ou base de sistemas administrativos.

---

## 🚀 Funcionalidades

✅ Listagem de solicitações de reembolso  
✅ Visualização de detalhes  
✅ Criação de novos reembolsos  
✅ Atualização de informações  
✅ Exclusão de registros  
✅ Navegação SPA com React Router  
✅ Validação de dados com Zod  
✅ Integração com API via Axios

## 🛠️ Tecnologias utilizadas

| Tecnologia | Descrição |
|-------------|------------|
| **React** | Biblioteca principal de UI |
| **TypeScript** | Tipagem estática e segurança |

| **React Router** | Roteamento SPA |
| **Tailwind CSS** | Estilização moderna e responsiva |

| **Axios** | Cliente HTTP para API |
